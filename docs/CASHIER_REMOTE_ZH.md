# 收银售后系统远程控制接入

这个分支把 RustDesk 开源客户端接入收银售后管理系统。

## 已实现

- 门店收银机可使用一次性安装码登记。
- 登记后自动写入自建 RustDesk ID 服务器、转发服务器和公钥。
- 门店收银机每 60 秒向管理后台报告在线状态。
- 门店收银机每 2 秒查询一次待连接会话。
- 管理后台的 `cashier-remote://` 链接可自动打开控制端。
- 一次性票据在控制端换取临时钥匙，临时钥匙只保存在内存中。
- 临时钥匙只能用于远程桌面，验证成功后立即销毁。
- 连接建立和断开时向管理后台报告会话状态。

## 云端构建

1. 打开 GitHub 仓库的 `Actions` 页面。
2. 选择 `Flutter Nightly Build`。
3. 点击 `Run workflow`。
4. 选择 `codex/cashier-remote-integration` 分支。
5. 在 `cashier_api_base_url` 中填写管理后台的 HTTPS 地址，例如：

   ```text
   https://api.example.com
   ```

6. 等待构建完成后下载 Windows x86_64 构建产物。

生产后台必须使用 HTTPS。本机测试允许使用 `http://localhost:3000`。

## 门店收银机登记

1. 在管理后台为门店生成一次性安装码。
2. 在门店收银机打开 PowerShell。
3. 进入 RustDesk 安装目录。
4. 执行：

   ```powershell
   .\rustdesk.exe --cashier-enroll 一次性安装码
   ```

5. 看到“设备登记成功”后，管理后台应在约 60 秒内显示设备在线。

安装码、设备密钥、远程票据和临时钥匙都不能发送到聊天、日志或截图中。

## 当前限制

- 首版使用每 2 秒轮询，客户数量增大后应升级为长轮询或 WebSocket。
- 当前先验证 Windows x86_64，其他系统尚未进行真实设备联调。
- 分发定制客户端和提供网络服务前，需要落实 AGPL-3.0 源码提供方案。
